# Open Knowledge Format (OKF)

OKF is a Markdown interchange format in the Google Cloud Knowledge Catalog project. Its documented purpose is sharing data-team knowledge such as tables, APIs, metrics, and playbooks.

Primary references:

- [Google Cloud announcement](https://cloud.google.com/blog/products/data-analytics/how-the-open-knowledge-format-can-improve-data-sharing)
- [Knowledge Catalog OKF specification](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/HEAD/okf/SPEC.md)

## What Not to Infer

- Google does not document OKF as a Google Search, AI Overview, AI Mode, ranking, or citation feature.
- No public search crawler is documented as discovering an `/okf/` marketing-site bundle.
- Its location in a Google Cloud repository does not make a marketing-site adaptation an endorsed SEO tactic.
- It is not an alternative to semantic HTML, a sitemap, truthful metadata, or ordinary internal linking.

Do not recommend a site-wide OKF bundle, third-party generator, or plugin for SEO/AIO. Do not compare speculative adoption to early schema.org adoption.

## When It May Be Relevant

Consider OKF only when the user has a genuine Knowledge Catalog or cross-tool data-documentation use case and accepts the maintenance cost. In that case:

1. Read the current specification and product documentation.
2. Confirm the intended importing consumer.
3. Pin the specification revision.
4. Keep the authoritative source and generated bundle consistent.
5. Measure success as documentation interoperability, not search visibility.

If the user asks whether OKF improves AI-search visibility, the current answer is: no documented effect; monitor primary sources rather than deploying it speculatively.
