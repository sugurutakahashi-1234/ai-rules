# コーディング規約

## 変更の作法

- **既存ファイルの編集を優先し、新規ファイル作成は最小限にする。**
- 「意図的な重複」をコメントの言い訳で残さない。同じ実装が 2 箇所に要るなら共有の置き場へ昇格させる。

## コメント

**WHY だけを残す。** 以下は書かない。

- WHAT（コードを読めば分かること）
- 日付・履歴・変更差分
- TODO の進捗
- `// =====` のような区切り線

## TypeScript

- `strict` を有効にする。
- `null` は**意味のある不在**にのみ使う。ありえないケースや degenerate なケースは `""` や自然な既定値に倒し、無意味な null 分岐や第三の状態を作らない。

## 時刻

**内部は UTC、表示は JST。** DB / API は UTC の ISO 8601 で持ち、UI 表示のタイミングで JST に変換する。
