# 実行できない手順はスクリプトにして渡す

対話入力（マスターパスワード・2 段階認証）が要る、安全判定で止められる（シェル起動ファイルへの書き込み・資格情報の投入）、ルールでユーザーに残してある。こういう手順は、長いワンライナーを貼ってもらうのではなく、1 本のスクリプトを作業用の一時ディレクトリに書いて絶対パスを渡し、ユーザー自身の端末で実行してもらって出力を貼り戻してもらう。ワンライナーは途中のどこで落ちたか読めず、貼り戻された出力で続きを判断できないため。

知らないと踏む罠:

- Claude Code の `!` 前置は隠し入力を受け付けない。パスワードを聞くコマンドは「ご自身のターミナルで」と明示する
- macOS の `awk` は `-v` に改行入りの文字列を渡せない。複数行の挿入は `python3 -I` か `perl` のヒアドキュメントで書く
- 元ファイルに直接リダイレクトしない（`cp f f.bak; tool f.bak > f` は tool が失敗した時点で `f` が空になる）。`mktemp` に生成し、空でないことを確かめてから `mv` する
- 貼り戻してもらう出力に秘密が混ざらないよう、値は文字数と種別だけ表示する
